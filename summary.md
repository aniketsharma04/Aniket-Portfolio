# Project Summary: Aniket Portfolio

This project is a modern and responsive personal portfolio website built using **Next.js 14** and **React 18**. It is designed to showcase Aniket's projects, experience, and skills in a clean, fast, and visually appealing manner.

## Key Information:

- **Purpose**: To provide visitors with a quick overview of Aniket's professional profile.
- **Live Portfolio**: [https://portfolio-main-86tq.vercel.app/](https://portfolio-main-86tq.vercel.app/)
- **GitHub Repository**: [https://github.com/aniketsharma04/Aniket-Portfolio](https://github.com/aniketsharma04/Aniket-Portfolio)

## Tech Stack:

- **Frontend**: Next.js 14, React 18, JavaScript (ES6+), Tailwind CSS / CSS, Framer Motion.
- **Deployment**: Vercel.

## Core Features:

- **Responsive Design**: Adapts to all screen sizes.
- **Modern Tech Stack**: Utilizes the latest in Next.js and React.
- **Dynamic Project Showcase**: Displays projects with details, tech stacks, and links.
- **Smooth Animations**: Implemented with Framer Motion.
- **Fast Deployment**: Optimized for speed and deployed via Vercel.
